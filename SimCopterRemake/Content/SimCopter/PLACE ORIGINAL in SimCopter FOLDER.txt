Put your original SimCopter (1996) game files in THIS folder.

SimCopter Remake ships none of the original game's data: it reads the city maps,
models, bitmaps, sounds and tuning tables straight out of a real install. Without
them the main menu comes up but no city will load.

Copy the CONTENTS of your SimCopter installation directory in here, so that this
folder ends up looking like:

    SimCopter\bmp\
    SimCopter\cities\
    SimCopter\geo\
    SimCopter\sound\
    SimCopter\tweak\
    SimCopter\SimCopter.exe
    ...

Do NOT copy the folder itself in - there should be no SimCopter\SimCopter\bmp.

You can delete this file once the game files are in place.
